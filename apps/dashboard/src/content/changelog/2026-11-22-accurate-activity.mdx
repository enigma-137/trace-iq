Background traffic no longer makes people look active. "Last seen" now moves only when someone actually does something, not when an idle tab polls your API or reports a web vital.

- The Users page shows who is **Online** (seen in the last 5 minutes), and "Active" is now **Active (7d)**.
- A person's **Sessions** count is their real number of sessions.
- Retention counts identified users by default, so it lines up with the Users page. Switch to **Everyone** to include anonymous visitors.
- **Fixed:** events sent with a clock set in the future no longer appear ahead of time.
