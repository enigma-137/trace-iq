Errors now connect to the tools you fix them in.

- **Linear:** create a Linear issue from an error, or turn on auto-create for errors that cross a threshold. Closing the issue in Linear resolves the error, and reopening it reopens the error.
- **GitHub:** link a repository and stack frames on error pages link to the exact line. Setup arrives as a one-click pull request, and its commit is reported as the release.
- **Settings → Integrations** now shows GitHub, Linear, Slack and Telegram as cards with their status, so you can see what's connected at a glance.
