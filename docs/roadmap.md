# Roadmap

## Phase 1: Foundation

- Monorepo structure.
- Shared TypeScript contracts.
- API, dashboard, marketing, SDK, and docs scaffolds.
- Event and timeline schema.

## Phase 2: Ingestion

- SDK event transport.
- API validation.
- Queue-backed ingestion.
- PostgreSQL persistence.

## Phase 3: Analytics

- Funnel definitions and result computation.
- User timelines.
- Segmentation.
- Retention queries.

## Phase 4: Replay

- Replay capture abstraction.
- rrweb integration.
- Replay storage and playback surfaces.

## Phase 5: Intelligence

- Insight generation service.
- Drop-off and anomaly detection.
- Device-specific conversion diagnostics.
- AI-assisted recommendations.
